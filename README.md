# Morrow website

Public static marketing site and privacy policy for Morrow, an Android dot-calendar wallpaper studio.

- Website: https://hardahmm.github.io/morrow-website/
- Privacy policy: https://hardahmm.github.io/morrow-website/privacy/
- Support/privacy contact: waytokairo@gmail.com

## Hosting and updates

This repository contains only public website content. The Android app source and APK are not published here. GitHub Pages serves the root directory of the `main` branch. `.nojekyll` disables Jekyll processing. All site assets are local, and relative links work under the repository's Pages base path.

Edit the HTML, `theme.css` or `studio.js`, then push to `main`. GitHub Pages rebuilds the website. Check both public URLs after updates. To preview locally, run `python -m http.server 8768` in this directory.

The homepage demo is explicitly a concept, not a screenshot or a complete app editor. There is no public Play download link until a release exists. The site has no tracking scripts, external font requests, forms or app cookies. GitHub Pages processes hosting traffic under GitHub's own privacy statement.

## Privacy maintenance

Review `privacy/index.html` against the exact release before using the URL in Play Console. Its current scope is the offline build with no active advertising or analytics. Update the effective date and disclosures before changing collection, sharing, SDK activation, permissions or processing. Link the public policy inside the Android app separately. A published policy does not itself complete the app's Data safety declaration.

## Assets

`assets/morrow-mark.svg` is the existing Morrow brand mark. `assets/kite.webp` is the original generated onboarding artwork from the Morrow project; its use is labeled on the homepage. No owner-supplied reference images or third-party wallpaper characters are distributed by this site.
